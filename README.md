# OptiForge Desktop — téléchargements

Dépôt de distribution d'OptiForge Desktop : installateurs Windows, macOS (Apple Silicon et Intel) et Linux,
signés pour le mécanisme de mise à jour intégré, avec le manifeste `latest.json`. Le code source est privé.

- Windows : `OptiForge.Desktop_<version>_x64-setup.exe`
- macOS : `OptiForge.Desktop_<version>_aarch64.dmg` (Apple Silicon), `OptiForge.Desktop_<version>_x64.dmg` (Intel)
- Linux : `OptiForge.Desktop_<version>_amd64.deb`, `OptiForge.Desktop_<version>_amd64.AppImage`

Les packages ne sont pas signés Apple/Authenticode : macOS demande « Ouvrir quand même » à la première ouverture.
